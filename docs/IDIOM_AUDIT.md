# Idiom audit

Generated by `scripts/idiom_audit.wj`; do not edit by hand. Regenerate with `--write`; CI runs `--check`.

The audit counts the forms in `packages/` and `apps/` that idiomatic Windjammer does not need: clones the compiler infers, explicit borrows, width casts, `.unwrap()`, string building with `+`, Rust-style types and macros, and comments that describe a workaround. Each row is a line count. The target for every row in the first table is zero; a remaining use is either a gap recorded as `// wj-gap: <id>` or a line still to be rewritten.

Scanned 433 files, 59681 lines in 87 packages and apps.
